## 初识redis

### Redis概述与核心特性

* ```Redis```是什么？

  * ```Redis```是一种基于键值对的```NoSQL```数据库。与许多键值对数据库不同，```Redis```的值可以由多种数据结构和算法组成，并且由于所有数据都存放在内存中，其读写性能非常好。

* 8个重要特性：

  | 特性 | 说明 |
  | :-: | :- |
  | 速度快 | 官方读写性能可达10万/秒。主要归功于数据存储在纯内存中，使用单线程架构预防竞争问题，以及采用C语言实现 |
  | 多种数据结构 | 值支持五种基础数据结构：字符串 (```string```)、哈希 (```hash```)、列表 (```list```)、集合 (```set```)、有序集合 (```zset```)，还支持```Bitmaps```、```HyperLogLog```和```GEO```等高级数据结构 |
  | 丰富的功能 | 提供了键过期功能（可用于实现缓存）、发布订阅（可用于消息系统）、支持```Lua```脚本、简单的事务功能以及流水线（```Pipeline```）功能 |
  | 简单稳定 | 源代码相对较少（3.0版本后约5万行），使用单线程模型，不依赖外部系统类库。具有很高的稳定性，笔者维护的上千个实例中未出现因自身```bug```导致的宕机 |
  | 客户端支持多语言 | 提供了简单的```TCP```通信协议和```RESP```（```Redis```序列化协议），支持几乎所有主流编程语言的客户端 (```Java```, ```Python```, ```C++```等) |
  | 持久化 | 提供```RDB```（快照）和```AOF```（日志）两种持久化方式，确保内存数据在断电或机器故障时不会丢失 |
  | 主从复制 | 提供了复制（```replication```）功能，实现多个相同数据的```Redis```副本，是高可用```Redis```的基础 |
  | 高可用和分布式 | ```Redis Sentinel```（2.8版本起）提供了高可用功能（故障发现和自动转移）；```Redis Cluster```（3.0版本起）是官方分布式实现（高可用、读写分离和容量扩展） |

### Redis的使用场景

* ```Redis```可以做什么（典型应用场景）：

  * 缓存：提供键值过期时间设置和灵活的内存淘汰策略。
  * 排行榜系统：可方便地利用列表和有序集合数据结构构建。
  * 计数器应用：天然支持且性能优秀，例如视频播放数、电商浏览数等。
  * 社交网络：相对容易实现赞/踩、粉丝、共同好友、推送等功能。
  * 消息队列系统：利用发布订阅功能和阻塞队列功能，可满足一般消息队列需求。

* ```Redis```不可以做什么（使用边界）：

  * 数据规模：不适合存储大规模数据（例如每日数亿用户行为数据），因为数据存储在内存中，经济成本过高。
  * 数据冷热：不适合存储冷数据（不常访问的数据），这会浪费宝贵的内存资源。

### 用好Redis的建议

* 切勿当作黑盒使用：开发者不能只停留在会用```API```，必须了解```Redis```的原理，如单线程模型、持久化原理等，否则容易造成线上故障。
* 开发与运维同样重要：充足规模的```Redis```运维经验对用好```Redis```非常有帮助。
* 阅读源码：```Redis```代码量小且质量高，阅读源码能够加深理解，提高编码水平，甚至可以进行定制化。

### 正确安装与启动

* 安装：```Redis```兼容绝大部分```POSIX```系统（例如```Linux、OS X```），```Windows```用户建议通过虚拟机体验。
* 可执行文件（```Redis Shell```）： 包括 ```redis-server```（启动）, ```redis-cli```（命令行客户端）, ```redis-benchmark```（性能测试）,```redis-check-aof/dump```（持久化文件检查修复）,```redis-sentinel```（启动```Sentinel```）。
* 启动方式：生产环境推荐使用配置文件启动```redis-server {path}/redis.conf```，因为它提供了更大的灵活性。
* 操作客户端：```redis-cli -h {host} -p {port}```可通过交互式或命令方式连接，默认连接```127.0.0.1:6379```。
* 停止服务：应该使用```redis-cli shutdown```命令来优雅关闭```Redis```服务，关闭过程会断开客户端连接并生成持久化文件。切勿使用```kill -9```强制关闭，这可能导致数据丢失或资源不能优雅关闭。

### Redis重大版本 (1.6)

* 版本演变：

  | 版本 | 发布时间 | 主要特性概述 |
  | :-: | :-: | :- |
  | 2.8 | 2013-11-22 | 添加了部分主从复制功能，降低频繁全量复制的压力；```Redis Sentinel V2```，变为生产可用 |
  | 3.0 | 2015-4-1 | 添加```Redis Cluster```，填补了官方分布式实现的空白；全新的```embedded string```对象编码，优化小对象内存访问 |
  | 3.2 | 2016-5-6 | 添加```GEO```相关功能（地理信息定位）；新增```List```编码类型```quicklist```；从节点读取过期数据保证一致性 |
  | 4.0 | RC版 | 提供了模块系统方便功能扩展；```PSYNC 2.0```优化主从切换时的全量复制问题；提供了非阻塞```DEL```和```FLUSHALL/FLUSHDB```功能；```RDB-AOF```混合持久化格式 |
