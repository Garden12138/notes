## 读取数据

* 导入pandas：import pandas as pd
* 读取csv文件：data = pd.read_csv()
* 读取xls文件：data = pd.read_excel()

## 查看数据

* 查看数据概况：data.info()
* 查看数据描述性统计信息：data.describe()
* 查看数据规模：data.shape
* 查看数据各个字段的数据类型：data.dtypes
* 查看数据前n行数据：data.head(n)
* 查看数据后n行数据：data.tail(n)

## 处理数据

* 判断是否存在缺失值数据：data.isnull()
* 填充缺失值数据：data.fillna(1234)
* 丢失所有缺失值数据：data.dropna()
* 判断是否存在重复值数据：data.duplicated()
* 删除所有重复值数据：data.drop_duplicates()

## 算法测试

* 划分特征X与标签y：

   ```bash
   X = data['特征列名']
   y = data['标签列表名']
   ```

  若出现多维特征，获取特征时只需删除标签：

  ```bash
  X = data.drop(columns=['标签列表名'])
  y = data['标签列表名']
  ```

* 按比例（如8:2）随机训练集和测试集：

  ```bash
  from sklearn.model_selection import train_test_split
  
  X_train,X_test,y_train,y_test = train_test_split(X, y, test_size = 0.2, random_state=2020)
  ```

* 将训练集和测试集的特征值转换为二维数组：

  ```python
  x_train = x_train.values.reshape(-1, 1)
  X_test = X_test.values.reshape(-1, 1)
  ```

* 定义模型（如逻辑回归模型），使用训练集训练模型：

  ```bash
  from sklearn.linear_model import LogisticRegression
  
  model = LogisticRegression()
  model.fit(X_train, y_train)
  ```

​  随机森林模型：from sklearn.ensemble import RandomForestClassifier

​  决策树模型：from sklearn.tree import DecisionTreeClassifier

​  K近邻模型：from sklearn.neighbors import KneighborsClassifier

* 输出测试集的准确度：

  ```bash
  accuracy = model.score(X_test, y_test)
  print(accuracy)
  ```

* 输出测试集的预测值：

  ```bash
  y_test_pred = model.predict(X_test)
  print(y_test_pred)
  ```

## 绘图部分

* 导入pyplot：import matplotlib.pyplot as plt

* 设置图表标题：plt.title('图标标题')

* 设置图表x轴：plt.xlabel('x轴标签')

* 设置图表y轴：plt.ylabel('y轴标签')

* 绘制散点图关键部分：

  ```bash
  import matplotlib.pyplot as plt

  plt.scatter(x=x, y=y, color='颜色', s=6, alpha=0.7, edgecolor='边框颜色' # x为横坐标，y为纵坐标，color为点的颜色，s为点的大小，alpha为透明度，edgecolor为边框颜色
  )

  plt.xlim(0, 100) # 设置x轴范围
  plt.ylim(0, 100) # 设置y轴范围
  ```

* 绘制热力图关键部分：

  ```bash
  import matplotlib.pyplot as plt

  fig, ax = plt.subplots()  # 创建子图画布和坐标轴对象
  heatmap = ax.imshow(data, camp='viridis') # 绘制热力图，data为数据矩阵，cmap为色彩映射方法

  for i in range(data.shape[0]):  # 遍历数据，在每个单元格显示保留2位小数的数值
      for j in range(data.shape[1]):
          ax.text(j, i,
                  f'{data[i, j]:.2f}',
                  ha='center', #   水平对齐方式
                  va='center'  #   垂直对齐方式
          )
  ```
